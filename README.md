# 星梦奇境 · 独立游乐项目

GitHub Pages 版，仅包含四个可单独进入的实时 3D 游乐设施：

- `/balloon/`：云上星穹 · 热气球升降塔
- `/teacup/`：瓷梦茶会 · 旋转茶杯
- `/pirate/`：黑帆湾 · 海盗船
- `/rainbow/`：彩虹滑道机

根目录 `index.html` 是四个项目的入口列表。所有路径均为相对路径，可直接部署到 GitHub Pages 项目子路径。

部署：将本目录全部内容上传到仓库根目录，在 Settings → Pages 选择 `main` / root。`.nojekyll` 已包含。
