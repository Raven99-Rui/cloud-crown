# 黑帆湾 · 海盗船 / BLACKSAIL BAY

一座可以在浏览器里环视、细看、登船并亲手加力的 **3D 海盗船机动游戏**。

整艘船、A 字支架、海洋、岛屿、棕榈、入口牌坊与远景城堡全部由 Three.js 实时建造；风、海浪、木桅吱呀、海鸥与汽笛由 Web Audio 实时合成。没有视频，也没有外部图片或音频素材。

## 现在进入

**http://127.0.0.1:4173/pirate/**

如果服务没有在运行，在项目根目录执行：

```bash
node scripts/server.mjs
```

不需要 `npm install`，不需要构建，也不依赖 CDN。Three.js r180 与 addons 已随仓库放在 `vendor/three/`。

## 可以玩什么

- **自由环视**：拖动旋转视角，滚轮/双指缩放，看船、看海、看整座岛。
- **四处细节**：右下「探索视角」或场景里的金色圆点，可以把镜头带到船首骨雕、航海舵轮、海盗旗与入口牌坊；镜头移动时 HUD 会收起，只留一张羊皮纸细节卡。
- **登船跟拍**：点击「登上黑帆号」，镜头会贴近船身，跟随它一起掠过海面。航行中可继续拖动环绕、滚轮拉近。
- **真实摆荡**：船围绕固定轴做单摆运动；底部最快、两端最高。摆幅可在 30°–78° 之间调整，航行中按空格或「再荡高一点」继续加力。
- **暮色 / 夜航**：右上角切换。入夜后天空、海水变深，船灯、码头灯、窗户与星空亮起。
- **实时声景**：海潮、风、木头受力、绳索轻响、远处海鸥与开船汽笛；默认静音，点击右上声音按钮开启。
- **移动端适配**：竖屏下自动调整构图、隐藏视角栏、保留触摸热点与可调摆幅的登船台。

## 场景里有什么

- **黑帆号**：手工搭出的双层船壳、船首鎏金骷髅、獠牙船首像、八辐舵轮、红丝绒长椅、黄铜窗、缆绳与索具、两道大旗、三角信号旗串、船灯与炮门。
- **摆荡结构**：蓝绿描金的 A 字支架、轴线、罗盘徽章、支撑桅、绳索与彩旗；船体由两条鎏金吊臂悬挂在轴心。
- **黑帆湾**：分层石岛、放射状石板广场、罗盘玫瑰、入口牌坊「海盗船」、售票亭、木桶/宝箱/铁锚、棕榈、礁石与潮沫。
- **远景**：纸雕感云层、海鸥、灯塔般的远岛塔楼与航标。

## 技术说明

- **无外部依赖**：Three.js r180 本地模块 + 原生 ES Modules，无打包器、无 CDN。
- **程序化建模/贴图**：船体、木纹、石板广场、牌匾、旗帜、骷髅、云层与水面法线贴图均由 Canvas 2D / Three.js 几何体生成。
- **交互式摆荡**：以固定轴为圆心的阻尼单摆视觉模型，摆幅平滑爬升；HUD 的摆角、离地、船速与 G 值由同一组物理量实时推导。
- **动态细节**：布料旗帜逐顶点起伏、三角旗串 InstancedMesh 飘动、乘客手臂随摆荡抬起、灯球闪烁、棕榈叶摆动、海鸥绕岛。
- **性能优化**：加载时按材质合并静态壳体/支架/道具，把 draw call 从约 1,470 降到约 610；移动端关闭阴影并使用更低像素预算。
- **可直接截图**：`scripts/shot.ps1` 用本机 Chrome 无头模式在固定时间点抓取预览图，方便回归比对。
